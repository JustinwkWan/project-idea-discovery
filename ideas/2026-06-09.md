## 2. Lightweight Markdown Knowledge Base

**Source:** [GitHub Trending](https://github.com/refactoringhq/tolaria)

**Scores:** Usability 8/10 · Tokens S · Time ~22h · Novelty 5/10 · Risk low

**The pitch:** A desktop (Electron/Tauri) or web app for organizing markdown notes with local full-text search, tagging, and optional bidirectional linking. Faster and simpler than Obsidian, with a focus on no vendor lock-in (plain markdown files).

**Suggested approach:** Frontend: React + local file API (Tauri for native, or use simple Node/Python backend). Store notes as plain markdown. SQLite for metadata/index. Focus on snappy search and clean UI.

## 3. Local LLM Benchmark & Advisor

**Source:** [GitHub Trending](https://github.com/Andyyyy64/whichllm)

**Scores:** Usability 7/10 · Tokens M · Time ~24h · Novelty 6/10 · Risk med

**The pitch:** A tool that profiles a user's hardware and benchmarks open-source LLMs (Ollama, LLaMA.cpp, vLLM) to recommend which model and configuration will give best throughput/latency/accuracy trade-off. Saves users weeks of trial-and-error.

**Suggested approach:** Detect hardware (CPU, GPU, VRAM, storage). Auto-download small, medium, large model variants. Run standardized benchmarks (latency, throughput, memory) on each. Score and rank. Store results as reference for future users.
