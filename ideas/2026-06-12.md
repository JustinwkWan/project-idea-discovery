## 3. AI agent security auditing tool

**Source:** [GitHub Trending](https://github.com/NVIDIA/SkillSpector)

**Scores:** Usability 6/10 · Tokens M · Time ~30h · Novelty 8/10 · Risk med

**The pitch:** SkillSpector hints at a critical emerging problem: as teams deploy AI agents with custom skills/tools, how do you detect prompt injection, supply chain attacks, or capability misuse before runtime? Current solutions are either generic SAST (too noisy) or manual code review (doesn't scale).

**Suggested approach:** Build an auditor that parses agent skill definitions (JSON/YAML), analyzes function signatures and docstrings for injection risk, checks for suspicious patterns (subprocess, eval, file write), and reports with remediation. CLI tool + VS Code extension. Leverage AST parsing and heuristic rules.
