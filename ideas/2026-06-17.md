## 2. Codebase Memory MCP: Indexable Code Intelligence

**Source:** [GitHub Trending](https://github.com/DeusData/codebase-memory-mcp)

**Scores:** Usability 8/10 · Tokens M · Time ~15h · Novelty 7/10 · Risk low

**The pitch:** An MCP server that indexes entire codebases into a persistent knowledge graph for fast code intelligence. Useful for devs who need semantic search, dependency tracing, or instant onboarding into large repos. Solves the "where do I find X" problem at scale.

**Suggested approach:** Python/Rust backend with graph DB (sqlite + custom indexing). Parse source files into AST, extract symbols/imports, store in knowledge graph. MCP protocol means it works with Claude Code and other LLM tools. Low risk because it's deterministic code parsing.
